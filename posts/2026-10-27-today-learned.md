클로드 코드와 함께 마크다운 글을 블로그로 바꿔 주는 프로젝트를 만들었습니다. 프레임워크 없이 HTML, CSS, JavaScript만 썼더니 각각이 맡는 역할이 또렷하게 보였습니다.

## HTML: 내용과 구조

HTML은 페이지에 **무엇이 있는지**를 정합니다.

- `header`, `main`, `article`, `footer` 같은 시맨틱 태그로 글의 구조를 표현합니다
- 제목, 문단, 목록, 표, 이미지가 모두 HTML 요소입니다
- 이 블로그에서는 마크다운을 HTML로 바꾸는 것이 핵심 작업이었습니다

## CSS: 모양과 반응형

CSS는 **어떻게 보이는지**를 정합니다.

- 색, 글꼴, 간격을 `:root`의 CSS 변수로 모아 두면 테마를 바꾸기 쉽습니다
- 라이트와 다크 색을 변수 값만 바꿔서 전환합니다
- `@media` 쿼리로 모바일 화면과 데스크톱 화면에 맞게 배치를 조절합니다
- 한글은 `word-break: keep-all`로 단어 단위로 줄바꿈해야 읽기 편합니다

## JavaScript: 동작

JavaScript는 **무엇이 움직이는지**를 맡습니다.

- 다크모드 버튼을 누르면 `data-theme` 값을 바꾸고 `localStorage`에 저장합니다
- 페이지를 열 때 저장된 테마를 먼저 적용하면 화면이 깜빡이지 않습니다
- Node.js 빌드 스크립트가 마크다운 파일을 읽어 HTML 파일로 만들어 줍니다

## 한눈에 보기

| 기술 | 역할 | 이 블로그에서 |
| :--- | :--- | :--- |
| HTML | 구조 | 글 본문과 페이지 뼈대 |
| CSS | 모양 | 다크모드, 모바일 대응 |
| JS | 동작 | 테마 전환, 마크다운 변환 |

> 역할을 나눠서 생각하면 문제가 생겼을 때 어디를 고쳐야 할지 금방 보입니다.

## 정리

화면이 이상하면 CSS, 내용이 틀리면 HTML이나 변환 스크립트, 동작이 안 되면 JavaScript를 먼저 확인하면 됩니다.
